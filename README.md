# 太空數學探險

## 目前專案狀態

遊戲 v1 已實作，包含八關、兩種答題模式、多玩家紀錄、備份與離線支援。正式發布狀態與驗收限制見 [驗收紀錄](docs/VERIFICATION.md)。

### 本機執行

線上遊玩：**[太空數學探險](https://hikaruhen.github.io/space-math/)**（發布驗收狀態見下方紀錄）。

本機需要 Node.js 22.16 或更新的相容版本。

```sh
npm ci --legacy-peer-deps
npm run dev
```

開啟終端顯示的本機網址。`npm test` 驗證數學與回合，`npm run build` 產生 `dist/`。`npm run preview` 可檢查正式建置及離線功能；開發模式不註冊 Service Worker。

GitHub Actions 每次推送會測試、建置、保存靜態網站產物並發布 Pages，也可手動觸發部署。使用者已於 2026-11-20 確認公開儲存庫並免費發布。遊戲無後端，玩家與成績留在使用者自己的瀏覽器。

建置後也可雙擊 `開始遊戲.cmd` 啟動本機正式版。備份匯入／匯出用於不同裝置或網址間搬移紀錄；本機測試與正式網站的紀錄不會自動同步。

## 不可變更的已確認需求

1. 主題：太空探險；以平板觸控為主，橫向優先。
2. 算術：加法與減法；A1–A4（10以內），B1–B4（20以內）；共八關。
3. 一輪 **60 秒**；不限題數。
4. 每關均可選 **數字鍵盤**／**四選一**，兩種模式成績分開保存。
5. 答錯提示後**原題重試**；不能靠答錯跳題。
6. 多名玩家，成績與偏好各自獨立；音效預設開啟、可關閉。
7. **八關全部開放**，不強制解鎖。星球地圖、星級評價可作成就而非進入門檻。
8. 每輪有成績結算與本機歷史紀錄。
9. 部署目標 GitHub Pages，優先零後端靜態網站。

## 圖片的正確使用方式

圖片是視覺靈感／佔位素材，**實作時所有算式、字串、門檻與數學邏輯都以 Markdown 文件為準**；尤其概念資訊圖可能有排版與中文字誤差。最終遊戲 UI 不應直接將資訊圖作為整頁背景。
