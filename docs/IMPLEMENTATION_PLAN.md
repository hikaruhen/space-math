# 太空數學探險：已確認開發計畫

日期：2026-11-20。狀態：規劃完成；GitHub 儲存庫初始化，尚未實作遊戲。

## 需求優先順序

本文件記錄交接包閱讀後的確認與實作預設；與舊文件不同處以本文件為準。其餘數學與產品規則沿用 PRODUCT_SPEC.md、MATH_ENGINE.md。圖片僅供視覺參考。

使用者已確認：
- B1、B2、B4 每題至少一個值為 11–20；B3 每題確實進位或退位。
- 每局開始前選擇數字鍵盤或四選一，局中固定模式。

## 產品與介面

繁體中文、2D 卡通太空探險、橫向平板優先。八關全開放；每局有效遊玩時間 60 秒。答對推進火箭，答錯溫和提示並原題重試。玩家以暱稱及角色區分，各關、各模式成績獨立；無登入、廣告或內購。

流程：玩家選擇 → 全開放星球地圖 → 關卡與模式 → 3、2、1 → 遊玩 ↔ 暫停 → 結算。左側火箭、右側大字題目與操作；窄螢幕改直向排列。觸控目標至少 48×48 CSS px。音效預設開啟且可關；支援減少動態效果。

## 技術與資料流程

採 TypeScript、Vite、DOM 介面，零後端，GitHub Pages 為部署目標。Vitest 驗證核心、Playwright 驗證操作。

| 模組 | 介面與責任 |
|---|---|
| questionEngine | 接收關卡、模式、可注入亂數；輸出算式、未知位置、答案與選項 |
| gameSession | 管理準備、遊玩、暫停、中止、結算；使用可注入單調時鐘 |
| answerController | 鍵盤確認提交、選項單擊提交、輸入驗證與防重複提交 |
| scoring | 由作答事件累計完成題數、首次答對、錯誤、連擊、積分與耗時 |
| playerStore | UUID 玩家與回合、版本化 localStorage、備份接口 |
| ui / effects | 狀態呈現、操作、動畫與音效；效果不得阻擋答題 |

資料流：選擇 → 建立回合 → 出題 → 提交判定 → 更新統計 → 重試或下一題 → 截止結算 → 保存。

玩家、回合與題目紀錄欄位沿用 TECH_PLAN.md。以 playerId、levelId、answerMode 區分歷史；最高積分與最多完成題數分開呈現，不虛構同局綜合最佳。

## 明確預設與邊界政策

- 有限合法題池洗牌，耗盡再洗牌；避免連續相同題或加法交換等價題。
- A3、B3 加減均衡；A4 均為單一缺項；B4 一般與缺項各半，加減均衡，進退位至少四分之一。涉及零的題目抽樣目標不超過兩成；比例可配置。
- 四選一四項互異且合法、只有一個正解；每四題一組洗牌平衡正解位置。同題重試保持選項及順序。
- 鍵盤只接受 0–20、最多兩位數的合法整數；清除與空白不算提交，前導零正規化。A 區可輸入 11–20 作為錯誤答案，題目正解及四選一仍限 0–10。
- 準備倒數不占 60 秒。提交處理時有效時間 <60,000ms 才接受；達截止即拒絕提交，只結算一次。判定為同步處理，不受動畫回呼影響。
- 暫停、失焦或切背景遮蓋題目並停止有效計時；返回手動恢復。準備階段失焦也暫停倒數。重新整理不恢復未完成回合；中止不列入正式成績。
- 每完成一題 +100，首次答對再 +20；首次答對連擊達 5、10、15⋯各 +50。錯答立即斷連擊，重試答對不增加首次答對連擊。
- 平均完成時間由題目出現至答對，含重試、排除暫停；立即切題的處理時間計入下一題。未完成題不進入完成題數、首次正確率或平均時間，其錯誤提交仍保留。零完成題正確率及平均時間顯示「—」。
- A1 星級沿用交接門檻並標示「試行」；其餘顯示「待校準」。星級不鎖關。
- 本機資料無跨裝置同步承諾。資料損壞不自動覆寫原始資料；配額不足仍顯示當局結算並提示備份。
- JSON 匯入先完整驗證與摘要確認，再合併；同 ID 同內容略過，同 ID 不同內容拒絕整批匯入。離線功能於 P4 導入，更新不得打斷遊玩。

| P2 | 多玩家、偏好、本機歷史、獨立最佳、全開放地圖與星級 | 同名玩家不混用，正常結算紀錄重開保留 |
| P3 | 卡通美術、連擊獎勵、柔和倒數、減少動畫 | 回饋清楚、不遮題、不增加強制等待 |

每階段交付可執行增量，回報完成內容、未完成事項與下一里程碑。先核心後美術，不一次堆疊全部階段。

## 測試與完成條件

- 窮舉合法題池，檢查運算、值域、缺項、B 區限制、進退位，涵蓋 0、10、11、20。
- 檢查選項唯一正解、互異、固定重試順序、位置平衡及題池耗盡。
- 注入時鐘測試截止前後、雙結算防護、反覆錯答、連點、暫停恢復與背景切換。
- 驗證 5/10 連擊只獎勵一次、重試不重複完成、未完成題統計、零完成題。
- 驗證同名玩家、關卡及模式隔離、重開保留、損壞資料、配額不足、匯入衝突。
- Playwright 跑兩模式完整回合、響應式、靜音、無素材及減少動畫；Pages 子路徑與離線於 P4 驗證。
- 瀏覽器尺寸模擬與實體 iPad / Android 測試分開記錄；未實測不宣稱裝置驗收通過。

主要風險：兒童對 60 秒壓力的反應、零值與題型比例、星級尚未校準；瀏覽器背景節流與音效限制；localStorage 清除及容量；Pages 私人儲存庫的方案資格。部署階段確認可用方案，不自行公開儲存庫或購買方案。

首版不包含乘除法、雲端同步、老師後台、即時對戰。孩子試玩後再調整比例與門檻，變更需記錄版本。
