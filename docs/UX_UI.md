# 平板 UX/UI 與太空視覺指引

## 1. 導覽流程
選擇玩家 → 星球地圖（8關**全開放**）→ 關卡詳情（選數字鍵盤／四選一）→ 3-2-1 準備 → 60 秒遊戲 → 結算 → 再玩一次／選擇關卡／切換玩家。

## 2. 橫向平板畫面
- 頂部：玩家、A1–B4、剩餘時間、完成題數、暫停、音量。
- 主內容：左側火箭／星球進度動畫；右側大字算式、答案區、操作區。
- 主動作鍵（確認、選項）須有明確點擊態，無需精準點擊。
- 4:3 與 16:10 適應；窄螢幕時改垂直排列，仍可完成答題。
- 避免只靠顏色表示對錯：圖示及文字同步呈現。

## 3. 兩種答題模式
### 數字鍵盤
0–9、清除、確認；最多兩位數 0–20；僅按確認後送出；輸入清除不計錯；提交時可視覺防連點。

### 四選一
四個足夠大、分隔明確的數字卡；點擊即提交；錯誤卡顯示「再試一次」但不要直接提示正確卡；同題選項位置固定不變。

## 4. 動效
- 答對：火箭前進、短音效、短暫星星粒子，立即可進下一題。
- 答錯：柔和提示、不羞辱，不凍結作答太久。
- 連擊：每達到一個里程碑播放小獎勵，不干擾計算。
- 最後 10 秒：非侵入式倒數提示，不能造成感官壓迫。
- 動畫可減量；低效能裝置採低粒子量策略。

## 5. 暫停／中斷
- 暫停遮蓋題目與選項，提供恢復或離開（中途離開是否記錄須事先明確定義，建議不計為已結算成績）。
- 頁面失焦／背景化則自動暫停；從背景返回必須手動恢復。
- 倒數計時以累積有效前台遊戲時間為準。

## 6. 素材約束
`assets/visual_concept_infographic.png` 僅為**視覺概念**，不應作為可用的 UI 定稿或數學規格來源。圖中可能有文字渲染瑕疵；不可把圖上數字、規則或示例直接複製進遊戲邏輯。
`assets/*.svg` 是本包原創佔位用圖，可自行替換成更精緻的遊戲素材。請保留 UI 文字與圖形資產的分層，以利無障礙、響應式及語言調整。
