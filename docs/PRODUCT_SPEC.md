# 太空數學探險 v2 產品規格

2026-11-23：使用者確認規劃並授權實作。本文件取代 v1 固定 60 秒及試行星級政策；其他文件衝突處以本文件為準。

## 學生與玩法

- 以小一、小二為主，保留太空主題、八關自由探索、數字鍵盤與四選一、多玩家及個別音效與減少動畫偏好。
- 預設 10 題探險：不限時，答對 10 題結束；保留 60 秒挑戰，從準備倒數後計有效時間。
- 錯題再練：回合後取前 5 道曾答錯或使用提示的題目，最多 5 題、不限時；重練再次遊玩可重做本次練習題。沒有待練題不顯示錯題入口。
- 答錯保留原題與同組選項，不靠猜錯跳題；答對立即換題，慶祝動畫不阻擋。
- 所有玩法支援暫停、背景暫停與遮題；未完成離開不記正式成績。

## 提示與成就

- 每題可按「幫我想想」；同題第 2 次錯誤提交自動顯示提示。
- 題型提示包含數量圖、湊十、先減到十、部分與整體。顯示已知數量及策略，不代填未知數。
- 手機開啟提示時移到提示區；「回到作答」收起提示並回到題目，使用提示標記保留。
- 任務完成即有抵達回饋；結算優先呈現完成題數、獨立首次答對、提示題數、下一步建議。其他資訊置於詳細紀錄。
- 使用提示後成功仍算完成，但不算獨立首次答對、不加首次或連擊獎勵。提示會中斷連擊。
- 不使用未校準的速度星級或宣稱已精熟。比較個人先前紀錄時只使用 v2 同關、同答題模式、同玩法資料。

## 成績與資料介面

- 每完成題 +100；獨立首次答對 +20；每連續 5 題獨立首次答對 +50。重試不扣積分。
- 新增 Gameplay：mission、challenge、review；回合增加 gameplay、targetCount、hintCount、attemptedCount、independentAccuracy；逐題增加 hintUsed。
- independentAccuracy＝未用提示且首次答對題數 ÷ 所有已提交答案的不同題數，包含最後未完成錯題；沒有提交則為 null。
- firstTryCorrectCount 在 v2 代表獨立首次答對；firstTryAccuracy 保留除以完成題數的舊欄位介面，新 UI 以 independentAccuracy 為主。
- 最佳與歷史依玩家、關卡、答題模式、玩法隔離。舊版回合歸 60 秒挑戰，歷史標記未記錄提示，不能推估提示使用情形。
- 備份結構升為 schemaVersion 2，仍接受合法 v1 備份；保留 space-math-v1 儲存鍵與舊回合內容。先驗證才升級外層格式，格式損壞保護原始本機值。
- 匯入合併保留原有相同 ID 衝突拒絕規則；資料僅在瀏覽器，不承諾跨裝置同步。
