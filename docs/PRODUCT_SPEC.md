# 正式產品需求（單一真實來源）

版本：v1.0 / 2026-11-20。狀態：規劃確認，未授權實作。

## 1. 產品定位
面向國小兒童的平板觸控加減法限時遊戲。以 60 秒短回合促進正確性、熟練度與心算速度，融合太空探險、火箭推進、星球關卡與成就回饋。遊戲不得以猜題、過量動畫或誤導積分掩蓋學習成果。

## 2. 使用者已確認的功能
- 主題：太空探險，2D 卡通風格。
- 平板優先，橫向優先；兼容手機及桌機的基本操作。
- 八關：A1、A2、A3、A4、B1、B2、B3、B4，**全部自由選擇，沒有解鎖門檻**。
- 每輪固定 60 秒（正式計時從開始挑戰後起算），60 秒內可連續完成不限題數。
- 每關皆支援 **數字鍵盤** 與 **四選一**；每個玩家的關卡／模式成績獨立統計，不能混榜。
- 答錯：立即明確提示，**保留原題**讓玩家重試。所有錯誤提交都計數，完成題數只有答對才增加。
- 多玩家：可建立暱稱與角色，分開儲存成績。
- 音效預設開啟，提供可見的靜音切換，重開頁面保留偏好。
- 每局結算至少顯示完成題數、首次答對題數、錯誤提交次數、首次正確率、最高連擊、積分、歷史最佳與星級（若足夠數據）。
- 遊戲設計無廣告、無付費抽獎、無需登入。

## 3. 預設政策（可在實測後調整，不應默默變更）
- 允許數字 0 參與運算及作為答案，並控制 0 相關題的比例。
- 計時開始前 3、2、1 準備倒數，不占用 60 秒。
- 以單調時鐘處理遊戲時間；手動暫停、頁面背景時自動暫停，暫停畫面遮蓋題目。
- 60 秒到時：已送出的答案先完成判定；尚未送出的題目不計入任何作答數。
- 四選一單擊即提交；數字鍵盤輸入後按「確認」才提交，不因輸入部分數字等於答案而自動提交。
- 輸入限制：0–20 的合法非負整數，至多兩位數；提交前避免空值、非數字與不必要前導零。
- 同題錯誤後維持同題與同組四選一選項（不洗牌、不替換），但應顯示錯誤回饋並允許重新提交。
- 答對後立即回饋、快速轉下一題；動畫不得阻擋作答流程。
- 關卡評價的題數門檻為暫定值，需以孩子實測校準；成績算法應可配置。

## 4. 指標清楚定義
**題目**指一個生成的算式，**提交**指玩家按下確認或四選一選項，**首次答對**指此題第一次提交即正確，**完成題數**指在倒數結束前最終答對通過的不同題目數。

- `completedCount`: 完成題數，每題最多 +1。
- `firstTryCorrectCount`: 首次答對題數，每題最多 +1。
- `wrongSubmissionCount`: 全部錯誤提交次數，包括同題多次重試。
- `firstTryAccuracy`: `firstTryCorrectCount / completedCount`；completedCount=0 時畫面顯示 `—`，不要當作 0% 混淆。
- `maxStreak`: 連續首次答對的最長序列。發生任何錯誤提交即中斷。
- `avgCompletionTime`: 各已完成題目在「有效遊玩時間」內的耗時平均（錯誤重試耗時包含在該題內；暫停時間不計）。
- `score`: 建議每完成題 +100，首次答對再 +20，每累積連續 5 題首次答對加 +50；須統一明確的連擊觸發規則，避免第 5 題被多次計獎。
- 歷史最佳應以 `(playerId, levelId, answerMode)` 區分，可分別保留「最高積分」「最多完成題數」等；不得誤稱為同一輪達成的綜合最佳。

## 5. 暫定星級（先實測校準）
A1 可作示例：一星完成≥5、首次正確率≥70%；二星完成≥10、首次正確率≥80%；三星完成≥15、首次正確率≥90%。其他關卡不得在缺乏測試資料時硬套 A1 門檻。未達一星者可顯示 0 星；關卡皆可自由選，不以星星鎖關。

## 6. 非功能需求
- 觸控目標建議至少 48×48 CSS px，正式平板版宜更大。
- 解題文字高對比、圖案不得壓住題目；操作時避免橫向／縱向捲動干擾。
- 短暫提示、可減少動態效果；音效可關閉。
- 即使素材未載入，數學核心功能仍可正常執行。
- 本機儲存，不承諾跨裝置同步。提供未來 JSON 匯入匯出的遷移接口。
- 兒童個資最小化：只需暱稱／本地識別碼，不收集照片、精確生日或聯絡資訊。

## 7. 首版非目標
- 乘除法、登入帳號、雲端同步、多人即時對戰、內購、廣告、老師班級後台、生成式 AI 即時出題。
- 不要求第一次交付就完成全部 P3 的精細視覺效果。
