# 測試與驗收清單

## A. 數學
- [ ] A1–A4 所有運算元、已知數、答案都在 0–10。
- [ ] B1–B4 所有運算元、已知數、答案都在 0–20。
- [ ] 不產生負答案、分數、小數或不合法多未知數題。
- [ ] B1 無個位進位；B2 無個位退位；B3 必須符合個位進位／退位。
- [ ] 四選一均為 4 個互不相同的合法整數，只有 1 個正解。
- [ ] 題庫耗盡不會卡住；重排策略與連續重複避免機制正確。

## B. 回合
- [ ] 準備倒數後才啟動完整 60 秒。
- [ ] 數字鍵盤須按確認才送出；四選一單擊提交。
- [ ] 答錯保留原題及同一組選項；每次錯誤提交記錄一次。
- [ ] 同一題即使錯很多次，答對後只增加 1 個完成題數。
- [ ] 非法／空白輸入不可提交，亦不算一次錯誤。
- [ ] 60 秒截止前提交的答案具明確判定順序，不發生雙結算。
- [ ] 連擊於錯誤提交歸零；第五題獎勵不會重複發放。
- [ ] 手動及背景暫停均遮蓋題目、停止有效遊戲時間，返回須明確恢復。

## C. 紀錄
- [ ] 至少兩名玩家可建立同名但不同 ID，且資料不混用。
- [ ] 同一關的鍵盤與四選一各自獨立紀錄、最佳成績不互串。
- [ ] 刷新頁面後玩家、音效設定、正常結算成績仍存在。
- [ ] 首次正確率依首次答對題數 / 完成題數，0 題顯示 `—`。
- [ ] A1 星級暫定門檻可配置，尚未校準的關卡不誤用其門檻。

## D. 平板／可用性
- [ ] iPad 4:3 與 Android 平板 16:10 橫向時題目與答案按鈕完整可見。
- [ ] 常見觸控目標至少 48×48 CSS px；無誤觸重複提交。
- [ ] 音效可關且重開後保留；若瀏覽器禁播音效不會影響遊戲。
- [ ] 動畫不遮擋答題、不造成 60 秒期間的強制等待。
- [ ] 減少動態效果設定有效；錯誤／正確訊息不只靠顏色。
- [ ] GitHub Pages 子目錄路徑下靜態資源正常載入。

## E. 誠實記錄待校準事項
- A1 的 1、2、3 星門檻是暫定值，B1–B4 等其他關卡星級須實測設計。
- 多久視為「平均每題時間」的起訖點、動畫切換時間是否計入，需要在 P0 設計時明確決定並測試。
- 暫停按鈕的位置、是否需限制每日局數等是 UX 可調項，不得先於核心功能。

## Definition of Done
功能能連續完成完整 60 秒回合；題目分類及答題計數測試通過；兩模式與多名孩子紀錄獨立；平板可用；沒有高優先未修正錯誤；規格偏差有清楚記錄。
