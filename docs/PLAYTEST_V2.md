# v2 角色試玩與改善驗收

日期：2026-11-23。版本 2.0.0。本輪修改本機版本，未推送或部署正式站。

## 完成與剩餘

已完成：10 題不限時任務、60 秒挑戰、最多 5 題錯題再練、漸進提示、提示使用與獨立答對分開計分、同玩法個人紀錄、v1 備份相容與 v2 備份、手機提示返回操作。

待真實使用者驗證：小一／小二閱讀理解、願意重玩的程度、長期計算精熟提升、實體 iPad／Android 觸控及音效。此處 93 分是工程與角色模擬的自評，不能宣稱兒童實測達 93 分，亦不能證明教學成效。

## 老師與學生角色的操作紀錄

以下為代理以角色觀點進行的瀏覽器操作與判讀，沒有訪談真實兒童。

| 視角／情境 | 實際操作與觀察 | 結果 |
|---|---|---|
| 初學學生：不想被時間催促 | 預設 10 題探險；超過 60 秒仍可繼續，答對第 10 題抵達 | 不需先追求速度就能完成任務 |
| 學生：同題連錯兩次 | 原題與四選一位置不變，第二次自動顯示數量圖或策略 | 能獲得具體協助，沒有靠答錯跳題 |
| 老師：提示是否灌高成績 | 人工求助／自動提示後答對，僅完成數增加 | 提示題不計獨立首次答對與連擊獎勵 |
| 學生：修正後再試 | 完成任務後點錯題再練、答對、再次重玩 | 重練題目保留，乾淨完成後沒有多餘錯題入口 |
| 熟練學生：連續答題 | 八關各跑鍵盤與四選一；60 秒挑戰完成第 10、11 題 | 立即換題、進度持續向前，第 10 題有抵達站點回饋 |
| 老師：最後一題答錯但未完成 | 前一題正確，最後一題錯誤直到時間結束 | 獨立首次正確率 1/2，不被舊完成題分母誤顯成 100% |
| 學生：暫停休息 | B4 兩模式暫停後推進模擬時鐘 90 秒，再恢復 | 題目遮蓋、答題區 inert，暫停不消耗有效遊玩時間 |
| 手機學生：提示看完找不到按鍵 | 首輪截圖發現上下捲動負擔；縮短裝飾區、增加「回到作答」 | 390×844 畫面可完整顯示數字按鍵；提示可關閉再回題目 |
